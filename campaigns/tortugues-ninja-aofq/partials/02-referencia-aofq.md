### Referencia rapida de campanya

::: cols
::: box
#### Format de missio

- Taula recomanada: **24" x 24"** per jugar en format de taula reduida.
- Si useu una taula de 4' x 4', dobleu les distancies d'escenari.
- Duracio normal: 5-6 rondes.
- Les interaccions son accions d'habilitat normals d'`AoFQ`.
:::

::: box
#### Marcadors comuns

- **Mutagen:** bidons, caixes o tolls porpra. El Clan intenta evacuar-los.
- **Pizza:** objectius de moral i humor; no són necessaris per guanyar.
- **Ordinador:** tauletes, terminals o portàtils del Clan amb missatges de Mr. K.
- **April:** civil important. Protegir-la sol donar informació o ajuda narrativa.
- **Màquina:** aparells que s'activen amb interaccions d'habilitat.
- **Portal:** objectiu final de fugida o entrada a una altra dimensio.
:::

::: box
#### IA simple

- Si pot atacar un heroi, ataca.
- Si no pot atacar, avanca cap a l'objectiu d'IA de la missio.
- Si hi ha un marcador d'alarma, mutagen, April, portal o maquina, l'enemic mes
  proper el tracta com a objectiu d'IA.
- En empat, trieu l'opcio que cree mes pressio sense trencar la missio.
:::

::: box
#### Reforcos

- Useu les regles oficials d'alerta (alertness) d'`AoFQ`.
- Quan una missio diga "desplega reforcos", desplegueu una onada del valor que
  corresponga a la dificultat triada.
- Si jugueu amb xiquets o primera partida, retardeu els reforcos una ronda.
:::

### Rellotges de campanya

::: cols
::: box
#### Mutagen del Clan

Comenceu amb **0 mutagen**. Quan el Clan del Peu controla o evacua un marcador
de mutagen, puja el rellotge:

- Mutagen menor: +1.
- Mutagen gran o camio: +2.
- Si arriba a **6**, l'Acte II comenca igualment i la Maquina de Mutagen inicia
  amb un event narratiu desfavorable.
:::

::: box
#### Missatges de Mr. K

Hi ha **5 missatges** possibles. Les Tortugues els aconsegueixen completant
ordinadors, proves o pistes marcades. Amb **4 o mes missatges** abans de
Technodrome, April descodifica la veu de Mr. K i els herois comencen l'Acte III
amb una pista clara sobre el panell de control.
:::

::: box
#### Pizza

La pizza no canvia les regles base. Cada pizza recuperada dona una nota
narrativa de moral. Si en teniu **4**, abans d'una missio podeu convertir-les en
un avantatge suau acordat a taula: una pista extra, desplegament 3" millor o
cancel.lar un event narratiu menor. No modifica perfils ni tirades oficials.
:::
:::
:::

::: {.panel tag="section"}
### Events narratius

Els events d'esta campanya estan inspirats en el format de campanyes narratives
`AoFQ`: apareixen abans d'una missio, entre missions o al començament d'una
ronda concreta. S'han escrit per crear ritme i consequencies, no per substituir
normes.

Quan un event demane un test de Força (Str), Destresa (Dex) o Voluntat (Wil),
useu una accio o test normal d'`AoFQ` amb l'heroi indicat. Les consequencies
afecten preparacio, reforcos, posicio de marcadors o ficcio de la missio següent.
:::

### Si no sabeu com interpretar una situació

::: cols
::: box
#### Prioritat narrativa

- Si una decisio protegeix April o civils, és coherent que done informació.
- Si una decisio deixa mutagen en mans del Clan, el rellotge de mutagen puja.
- Si una decisio fa molt soroll, puja l'alerta o entren reforcos.
- Si una escena queda massa difícil, convertiu la derrota en captura, fugida o
  pèrdua d'un objectiu secundari.
:::

::: box
#### Com parlar dels objectius

Expliqueu sempre què representa cada interaccio abans de tirar: obrir un
contenidor, calmar April, hackejar un terminal, arrossegar un bidó, bloquejar un
camio, activar una màquina o forçar un portal. Això fa que la missio siga una
escena narrativa i no només una llista de marcadors.
:::

::: box
#### Escala de dificultat

Per a una primera partida, useu menys enemics inicials i retardeu reforcos una
ronda. Per a una partida més dura, feu que els objectius del Clan siguen també
objectius d'IA i que una onada entre quan els herois completen un objectiu
principal.
:::

### Preparacio de cada missio

::: cols
::: box
#### Enemics inicials

Quan una missio diga "Enemics suggerits", trieu una combinacio que s'ajuste a la
dificultat de la vostra taula. Per a 2 herois, comenceu amb una onada menuda:
ninjas o Mousers i, com a molt, un elite. Per a 3-4 herois, afegiu un segon grup
o un mutant gran.
:::

::: box
#### Reforcos

Els reforcos representen el Clan entrant per clavegueres, carrerons, portes de
laboratori o passarel.les del Technodrome. Si no hi ha punt indicat, entren per
la vora més propera a l'objectiu que vol protegir el Clan.
:::

::: box
#### Controlar i evacuar

Un objectiu està **controlat** si al final de la ronda hi ha almenys un heroi a
3" i cap enemic a 3". Un objectiu està **evacuat** quan la missio diu que ha
arribat a una zona segura, ha eixit per una vora o ha sigut retirat de la taula
després d'una interaccio.
:::

::: box
#### Civils i aliats

April, Splinter i altres aliats narratius no bloquegen moviment ni línia de
visio llevat que ho acordeu. Si un enemic arriba a 1" d'un civil, considereu-lo
capturat, amenaçat o obligat a moure's, segons l'escena.
:::
